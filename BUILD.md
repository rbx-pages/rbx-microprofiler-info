## Building the ``.json``

First step is to ensure that the dependency classes are built and set up on the other repository.

``npm run build-tagData``

Then copy paste the JSON builder functions into a dummy file to make modifications with autocomplete support.

And then put it back on the other repository here https://github.com/karl-police/rbx-microprofiler-info-json/.


## Run dev test

``npm run dev``
